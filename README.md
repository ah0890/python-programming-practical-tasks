# Python Programming Practical Tasks

A collection of practical Python programming exercises covering loops, conditional statements, NumPy arrays, and Object-Oriented Programming through a simple Bank Account System.

## Project Objectives

- Practise using `for` loops to process repeated input.
- Apply `if` / `elif` / `else` statements to make decisions.
- Perform basic calculations such as totals, averages, and percentages.
- Learn how to create NumPy arrays and convert their data types.
- Understand Object-Oriented Programming (OOP) using classes, objects, constructors, and methods.
- Write clean, readable, and well-commented beginner-friendly Python code.

## Technologies Used

- **Python 3**
- **NumPy** (for Task 2)

## Planned Tasks

| Task | Title | Concepts |
| ---- | ----- | -------- |
| 1 | Sales Employee Tax Calculator | `for` loop, `if/elif/else`, user input, totals and averages |
| 2 | NumPy Array Data Type Conversion | NumPy arrays, integer to float conversion |
| 3 | Bank Account System | Classes, objects, constructors, methods, input validation |
